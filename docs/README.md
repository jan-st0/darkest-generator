# Documentation

This folder contains logic documentation for the Darkest Generator project.

## Files

- **diagram.md** — A Mermaid diagram detailing the team score heuristic design. Paste into your Mermaid viewer to render.

- **hero_data_scheme.yml** and **trinket_data_scheme.yml** — Template files describing data structures in `darkest_dungeon_data.yaml` with real example data.
